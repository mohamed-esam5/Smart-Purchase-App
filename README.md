# 📱 Smart Purchase App | تطبيق المشتريات الذكي

تطبيق إلكتروني ذكي ومطور لإدارة الفواتير والمشتريات المشتركة، وتوزيع الحسابات بين الأشخاص بدقة عالية. يهدف النظام إلى تتبع المدفوعات، واحتساب فترات السماح وتواريخ الاستحقاق تلقائياً بناءً على طريقة الدفع، وإدارة تسوية الحسابات والمتبقي بشكل مرن.

---

## ✨ المميزات الرئيسية للسيستم (Key Features)

* **🔐 حماية المسارات (Route Guard):** فحص حالة تسجيل الدخول لحظياً عبر Firebase Auth وتأمين الصفحات الداخلية.
* **🧾 إدارة وتوزيع الفواتير:** إضافة وتعديل كامل بيانات الفواتير وتخزينها سحابياً في Firebase Firestore.
* **📊 توزيع مخصص ودقيق للمبالغ:** تحديد نصيب كل شخص من الفاتورة يدوياً مع نظام تحكم يمنع الحفظ في حال عدم تطابق مجموع الحصص مع إجمالي الفاتورة.
* **⏳ احتساب تواريخ الاستحقاق تلقائياً:** منح 55 يوم سماح ليصبح الاستحقاق يوم 25 من الشهر التالي عند الدفع بـ Credit Card، أو طلب دفع فوري لوسائل الدفع الأخرى (Cash / InstaPay).
* **🔄 نظام تعديل كامل وبسيط:** زر تعديل موحد داخل الجدول يفتح الواجهة ممتلئة بالبيانات القديمة وتوزيع الأشخاص تلقائياً لتسهيل التحديث.
* **🗂️ منظومة الأرشيف:** نقل الفواتير المدفوعة بالكامل للأرشيف لحفظها، وحظر أرشفة الفواتير المعلقة.
* **🔀 فرز وتصفية متقدمة:** ترتيب الفواتير ديناميكياً حسب التاريخ، الإجمالي، حالة السداد، أو طريقة الدفع.
* **🌙 دعم الـ Dark Mode:** واجهة مستخدم مريحة للعين تتحول تلقائياً بناءً على وضع النظام أو رغبة المستخدم.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend):** HTML5, CSS3 (Variables & Grid), JavaScript (ES6 Modules).
* **قواعد البيانات والـ Back-End:** Firebase Auth & Firebase Firestore.
* **الأيقونات والخطوط:** Font Awesome 6.4.0 & Google Fonts (Cairo).

---

## 📂 الهيكل التنظيمي للملفات (Project Structure)

* `index.html` -> صفحة تسجيل الدخول.
* `dashboard.html` -> اللوحة الرئيسية والتحليلات.
* `bills.html` -> واجهة إدارة وتوزيع الفواتير (والمودال الخاص بالإصافة والتعديل).
* `payments.html` -> واجهة السداد ومتابعة حسابات ومتبقي الأشخاص.
* `css/` -> ملفات التنسيق والتصميم (global.css, bills.css).
* `js/` -> لوجيك العمل والربط مع الفايربيز (bills.js, payments.js, firebase-config.js).

---

## 🚀 طريقة التشغيل المحلي (Local Setup)

1. قم بتحميل المشروع أو عمل Clone للمستودع.
2. افتح ملف `js/firebase-config.js` وضع إعدادات الـ Firebase الخاصة بمشروعك.
3. شغل المشروع باستخدام أي بيئة تشغيل محلية مثل (Live Server) في VS Code.
